# tfabri.dev

Portfólio pessoal de **Thiago Fabri**, Back End Developer, construído com HTML, CSS e JavaScript puros.

🔗 **Live:** [tfabri.dev](tllfabri.github.io/tfabri.dev/)

## ✨ Funcionalidades

- **Troca de idioma (PT / EN)** — todo o conteúdo do site troca de português para inglês (e vice-versa) com um clique, sem recarregar a página
- **Tema claro / escuro** — alternância de tema com as cores adaptadas via CSS variables
- **Preferências persistentes** — idioma e tema escolhidos ficam salvos no `localStorage` e são restaurados na próxima visita
- **Totalmente responsivo** — layout adaptado para desktop e mobile
- **Seções**
  - **Início** — apresentação, badge de cargo, breve descrição e CTAs (contato e download de currículo)
  - **Habilidades** — grid de expertise técnica por categoria
  - **Projetos** — cards com imagem, descrição e tags de tecnologia
  - **Contato** — WhatsApp, e-mail, GitHub e LinkedIn

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis CSS, Flexbox, Grid, animações)
- JavaScript (Vanilla — sem frameworks ou bibliotecas)
